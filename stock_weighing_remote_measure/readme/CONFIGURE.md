To configure the tares available in the weighing screen:

1. Go to *Weighing > Configuration > Tares*.
2. Create a tare for every value you want to have at hand, setting:
   - The text displayed in the button.
   - The tare value and its unit of measure. It will be converted to the unit of
     measure of the weighed product.
   - The button color.
3. Reorder them with the handle or archive the ones you don't need anymore.
